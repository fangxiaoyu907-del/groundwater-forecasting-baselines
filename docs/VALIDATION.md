# 公开版验证记录

本地验证日期：2026-10-07。环境：Windows、Python 3.12.14、NumPy 2.2.6、TensorFlow 2.20.0、Keras 3.15.1、CPU。

## 已检查

- 完整测试集 43 项通过，无跳过：Ridge / Persistence / metrics 23 项，GWO 8 项，窗口与标准化 5 项，神经网络 5 项，演示 2 项。
- 三种神经网络的单层/多层前向传播、多输出形状与小批次训练；时间注意力沿时间轴归一化，参数梯度可达且有限。
- 使用临时的合成输入模型进行保存/加载往返检查；预测保持一致，测试文件自动移除，不提交任何权重。
- GWO 固定种子、目标调用次数、历史最优、边界与非法输入检查，以及目标函数修改输入时的内部状态保护。
- 训练限定标准化、恒定列、跨划分多步标签保护、Ridge 多输出增量及退化指标处理。
- `run_demo.py` 和 `run_demo.py --neural --epochs 3` 均正常完成，仅使用内存合成信号，不写数据或训练产物。

合成演示包含 360 个无量纲点、8 步历史、1/3 步提前量；完整目标样本的训练/验证/测试数为 210/68/68，4 个跨边界样本丢弃。Ridge 的正则参数仅在验证段选择；神经网络预处理只在训练段拟合，按验证误差选择内存中的最佳轮次权重。

## 不代表什么

这些检查验证代码结构和运行流程，不验证研究数据、论文结论或真实预测效果。神经网络默认仅训练 3 轮用于运行检查，可能明显弱于持续性基线；不能将这些指标用于证明模型优势。本仓库没有进行真实数据调参或生产部署。

原研究环境、私有实验配置、未公开方法及历史论文结果均不在验证范围。基础安装缺少 TensorFlow 时会明确跳过 5 项神经网络测试；完整 GitHub 测试流程要求安装并成功导入 TensorFlow 后才执行。

持续验证状态以 [GitHub Actions](https://github.com/fangxiaoyu907-del/groundwater-forecasting-baselines/actions/workflows/tests.yml) 为准。
