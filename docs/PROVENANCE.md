# 来源与整理边界

本仓库是对作者现有毕业论文实验工作区的有限、数据无关整理，不是原文件的整份镜像。

| 公开组件 | 来源与改动 |
| --- | --- |
| GRU / BiGRU / 时间注意力 | 原实验 `models.py` 已声明为重构代码而非找回的第一、第二篇源码。仅保留标准循环网络和单头时间注意力；拆除其他研究结构、特定实验分支和更新功能。中性命名，新增严格输入校验与新版序列化构建，使用公开测试环境。 |
| Ridge / Persistence / metrics | 从通用线性基线实验的数学部分提取。删去所有数据读写、井点信息和实验配置；增加多输出、训练限定拟合、形状和数值保护。 |
| GWO | 从重构实验搜索函数中提取候选初始化、历史候选排序、三精英更新和边界裁剪。目标函数由调用者传入；删去研究搜索空间、模型接口、数据依赖、缓存和日志。保留历史候选精英存档的变体，并非第一篇原始搜索源码或规范算法复现声明。 |
| 窗口、演示、测试及工作流 | 本次整理新增的独立工程辅助材料；仅用内存合成输入，未读取任何真实研究数据。 |

原工作区来源的 TensorFlow 2.10 注释不代表公开版可以复现该环境的结果。公开版针对 Python 3.12 / TensorFlow 2.20.0 做运行检查；训练预算、窗口和合成信号参数只是演示选择，不是论文参数。

第一、第二篇资料目录中未找到可确认的原始模型源文件。另有研究训练文件与未公开方法、私有数据和结果紧密耦合，本次不发布。不根据论文正文重写模型后将其冒充原作者历史源码。

没有上传研究文稿、补充材料压缩包、原始/处理后数据、模型权重、拟合统计、评价结果图或私有 Git 历史。
